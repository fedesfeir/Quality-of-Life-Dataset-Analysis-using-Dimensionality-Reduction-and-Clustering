# Quality-of-Life-Dataset-Analysis-using-Dimensionality-Reduction-and-Clustering
# Advances in Data Analysis and Statistical Modelling

This repository contains the project "Advances in Data Analysis and Statistical Modelling," which focuses on analyzing a Quality of Life 2024 dataset using various advanced statistical techniques, including data standardization, dimensionality reduction, and clustering methods.

## 🚀 Project Overview

The primary goal of this analysis is twofold:
1.  To apply **standardization** and **distance measurements** and compute **aggregate indices**.
2.  To utilize advanced **dimensionality reduction (PCA)** and **clustering techniques** to uncover patterns in the data and evaluate the performance of different methodologies.

The analysis was performed on a random subset of **60 cities** selected from the original dataset of 178 cities.

## 📊 Dataset

The project uses the [**Quality of Life 2024 dataset**](QLCit24.m), with each of the 60 cities characterized by the following nine indices:

* **Quality of Life Index (QLI)**
* **Purchasing Power Index (PPI)**
* **Safety Index (SI)**
* **Health Care Index (HCI)**
* **Cost of Living Index (CLI)**
* **Property Price to Income Ratio (PPIR)**
* **Traffic Commute Time Index (TCTI)**
* **Pollution Index (PI)**
* **Climate Index (CI)**

***The dataset used for this analysis is available within this repository.***
